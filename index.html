PROJECT_02TYPE: IoT · SafetySTATUS: Central Hackathon Finalist

Industrial Gas Leak Detection System

An industrial safety system that doesn't wait for someone to notice a problem. It combines gas, temperature, humidity, and occupancy sensors with AI camera monitoring to catch hazards and trigger alerts in real time.

ESP32 boards read MQ2 (gas), MQ7 (carbon monoxide), and DHT11 (temperature/humidity) sensors; a Python + computer-vision layer watches for occupancy and hazard conditions on top.

PROJECT_04TYPE: Edge/Fog · IoTSTATUS: Built

Real-Time Traffic Management System

Traffic lights that react to traffic, not a fixed timer. This system detects vehicles in a camera feed and estimates density in real time, using fog computing to keep decisions local and fast instead of round-tripping to the cloud.

YOLO handles vehicle detection on top of OpenCV, running against an ESP32-based embedded setup with fog computing for lower-latency decisions.
